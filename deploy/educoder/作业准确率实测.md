# EduCoder 作业准确率实测

2026 年 11 月 13 日，用 DSH `0.2.2-alpha.2` 从 Web API 分配作业、运行 DeepSeek、保存文件、提交并读取评测结果。题集由 12 道原创 JavaScript 编程题组成（10 道单文件、2 道多文件），共 76 个用例（24 个公开、52 个隐藏）。模型不接触隐藏输入或答案；QuickJS 在独立的 WebAssembly 环境运行提交，按预先写好的期望值判分。每次使用新建的模拟账号和独立作业状态。

| 运行 | 提交并通过 | 全流程通过率 | 判题结果 | 用时 |
| --- | ---: | ---: | --- | ---: |
| 第一轮，DeepSeek 官方 API `deepseek-flash` | 12/12 | 100% | 12 题均首评通过，76/76 个用例通过 | 51.3 秒 |
| 第二轮，同一模型和题集，增加保存顺序约束 | 9/12 | 75% | 已提交的 9 题均首评通过，54 个用例通过；其余 3 题未评测 | 46.3 秒 |

第二轮未完成的 3 题都收到官方 API 的 `402 Insufficient Balance`，其中 1 题已保存、未提交。两轮复用了同一题集，不能把样本加总来估计其他课程的正确率。首评正确率分母为实际提交题数；全流程通过率分母为分配题数。模型版本映射见 [DeepSeek 官方 API 更新记录](https://api-docs.deepseek.com/updates/#deepseek-v41-flash-1017-update)。

真实头歌额外验收一题：「Matplotlib子图绘制」。独立实例使用 OpenCode Go 的 `deepseek-v4.1-flash`，实际读取、保存并发起一次评测，平台计数从 1 增至 2。代码编译成功，平台公开用例图像比对失败，关卡仍为 0/1。题目要求参照内嵌图片，实测的模型链路只传了文本。更新读回规则后，对同一笔评测做只读核验，DSH 标记为「平台评测未通过」，未重复提交。公网实例未替换。

补齐读图后，用同一真实关卡复测。DSH 会话记录已确认题面 PNG（804 × 406）作为图片附件进入模型消息。DeepSeek 在隔离实例内读取、修改并评测代码，三次评测均未通过，关卡仍为 0/1。独立读图验收用两张不同的图，验证图片原始字节到达 DSH 的 Pi 模型接口，按图作答的替身两题均一次通过；图片返回 404 的第三题没有调用模型、保存或提交。另通过真实 OpenCode Go 转发发送一张合成图，DeepSeek 正确识别红色圆形和蓝色三角形。读图链路通过验收，真实题的图像比对仍未通过。公网实例未替换。

## 复现隔离题集

在仓库根目录执行。QuickJS 仅在启用该题集时加载。

```bash
judge_deps=$(mktemp -d)
npm install --prefix "$judge_deps" --no-audit --no-fund --ignore-scripts quickjs-emscripten@0.32.0
EDUCODER_BENCHMARK_QUICKJS="$judge_deps/node_modules/quickjs-emscripten/dist/index.mjs" \
  EDUCODER_FIXTURE_PORT=9299 node tests/fixtures/educoder-integration.mjs
```

另开终端，按 [隔离验收](README.md#educoder-账号评测和-web-面板) 的方式在独立的 DSH `0.2.2-alpha.2` Web 实例安装 EduCoder。加载凭据隔离补丁，配置 `DSH_EDUCODER_DEDICATED=1`、`DSH_EDUCODER_API_URL=http://127.0.0.1:9299/api`、`DSH_EDUCODER_PROVIDER=deepseek-official`、`DSH_EDUCODER_MODEL=deepseek-flash`。通过受保护的环境注入 `DEEPSEEK_API_KEY`，不要加载模拟模型配置。把该实例签发的回环启动 URL 放进 `DSH_EDUCODER_SMOKE_URL` 后运行：

```bash
node tests/educoder-accuracy.mjs
```

脚本只接受回环地址，并先检查 EduCoder 为模拟模式。结果输出 JSON，逐题记录题型、提交次数、首评及最终结果、判题用例数量和耗时。
