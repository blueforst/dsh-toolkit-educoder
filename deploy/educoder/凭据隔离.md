# 专用实例的凭据边界

专用 EduCoder 实例在基础组合之后加载 `credential-boundary.patch.yml`。同目录的 `credential-boundary.mjs` 必须随补丁一起挂载。该补丁关闭 DSH 的终端、工作区文件、文件上传、插件和配置管理、凭据设置、动态 Cordis、文件选择、工作目录变更工具与通用预设能力；仅保留宿主 `shell-env`、`sandbox-policy`、`bash-sandbox` 与 `working-directory` 以支撑 Worker 会话的隔离沙箱执行。DSH 本地凭据服务继续供 Host 使用，以普通文件持久化凭据，部署时以独立卷和主机访问权限保护。

固定版本 DSH 的 Session 控制器会注册经过登录校验的 `/api/file`，该路由接受主机绝对路径。补丁在 WebServer 的精确匹配层阻断此路由，并阻断两种文件上传入口、本机文件打开、目录操作和手动会话创建/提示词/Preset 切换接口。保留 Web 客户端所需的上传模块与空目录后端，使工作区导航和会话历史可用。

在 Agent 运行层，`dsh-educoder` 只允许自己创建的 Worker Agent 会话使用有限的 DSH 原生编码工具集合（`bash`/`pwsh`、`read`、`read_image`、`write`、`edit`、`glob`、`grep`、`job_*`），不挂载通用 `plan-mode`、`subagent`、`schedule`、`goal`、`skill` 或 Web 工具，且以 `sandbox-mode = workspace-write` + `approval-policy = never` 限制写操作停留在 EduCoder 共享工作区（`./cli/` 与 `./tasks/`）。当前任务的会话 Cookie 与签名密钥仅在单轮运行期间通过宿主 `ctx.shellEnv` 注册的按 `agent` 隔离内存映射注入 `DSH_EDUCODER_*` 环境变量，不写入模型提示词或磁盘文件，并在 `finally` 中立即撤销。

独立容器通过 SSH 隧道访问。保留容器与宿主之间的回环端口绑定，部署配置只加载受信任的插件，并使用专用凭据卷。浏览器取得启动凭据后具有该实例的管理员权限，适用于负责这些 EduCoder 账号的同一操作者。

公网组合在 HTTPS 登录后提供 DSH 原生管理员功能。该组合省略隔离验收补丁。EduCoder 面板沿用同一套认证，作业会话同样在 Worker Agent 内绑定所选账号的临时 `shellEnv` 上下文并限制原生编码工具集合。

固定 DSH 版本的本地测试使用模拟模型和关卡。结果为 DSH Web 登录后 200，Session 控制器可用，工作区 CLI 读写、评测与自愈闭环通过。文件下载和上传入口在未登录时返回 401，已登录时返回 403。路径带点段和编码点段时仍返回 403。
