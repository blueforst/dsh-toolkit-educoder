# M1 开发实例基线验收

2026 年 11 月 13 日在 `dsh-2c8g` 上验收。新实例使用 `dsh-educoder-dev` Compose 项目、独立的 DSH 主目录和工作区卷。安装前 Docker 已安装且未运行，服务器没有 DSH 运行实例。主机为 Ubuntu 26.04 LTS amd64、2 核、约 7.5 GiB 内存，安装前可用磁盘约 67 GB。宿主已有 Docker 29.1.3 和 Compose 2.40.3。GHCR、npm Registry 和 GitHub 可达。

| 项目 | 实测结果 |
| --- | --- |
| Toolkit 基线 | 上游提交 `68245671094f3faef4fd36c06c7827c442547da8`。快照校验、构建、静态检查和发布审计通过。使用实际 DSH 运行时执行 30 项测试，30 项通过，零跳过 |
| 运行时 | DeepSeek Harness `0.2.2-alpha.2`、Node `24.22.1`、Pi `1.4.0`、pnpm `10.15.1`、Python `3.13.5`。固定镜像摘要见 [Compose 配方](compose.yaml) |
| 原生安装 | `dsh plugin --profile web add --ignore-scripts --save-exact` 成功。插件清单确认 `@forst/dsh-toolkit 0.2.0`。安装包 SHA-256 为 `2be3d79305a96d3462b5c192f0b6fc38216defcfb7075d3b6246eda9f7d6ec81` |
| Web 认证 | 启动凭据换取 Cookie 后首页返回 200。未认证首页、资源接口和 Go 额度接口均返回 401。携带 Cookie 的跨源请求返回 403 |
| 工作区与 Session | 官方工作区控制器使用 `/workspace` 作为默认目录。通过真实 Chromium 界面创建工作区及 Session，发送消息后收到本地 Pi 替身流式回复 |
| Toolkit 界面 | 资源、Go 额度替身和会话费用均在 Web 界面渲染。费用投影从真实会话记录计算出模拟用量金额 0.0003 美元，刷新及窄屏浮窗检查通过，无前端异常 |
| 重启恢复 | DSH 容器重启后重新认证，在侧栏找到并打开原 Session。用户消息、助手回复、费用和模型选择器均可查看 |
| 隔离和资源 | 宿主 DSH Web 仅发布 `127.0.0.1:13080`。模型和采样替身不发布宿主端口。开发测试容器空闲时分别约用 404 MiB 和 17 MiB 内存，安装后宿主约 63 GB 可用磁盘 |

以上模拟模型调用通过 Compose 内部网络完成。Go 额度的界面验证使用固定样本，宿主保留的 OpenCode Go 凭据未注入本实例。真实供应商调用、EduCoder 平台登录与评测、Camoufox、Xfce 和 CUA 桌面路径需要各自的集成证据。
