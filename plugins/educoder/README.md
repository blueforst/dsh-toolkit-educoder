# DSH EduCoder 插件

在专用 DSH Web 实例中管理头歌账号、课程、作业和评测。每个账号独立保存会话、工作目录和任务进度。可以分配单项作业，或为多账号批量分配各自的作业。一个账号同一时间只运行一项任务。

在课程区选择账号和课程后，点击「一键通关」即可把该课程的未完成作业加入执行队列。已通关的作业会被跳过。需要人工处理或重试的作业可在任务队列查看。

真实作业的会话集中在 DSH 的「EduCoder」工作区。模型开始解题时会参考工作区的《解题经验》，评测通过后可追加一条通用经验。

同一份作业在上一轮模型请求后的 15 分钟内重试或进入已核验的下一关时，优先复用原 DSH 会话。下一关追加新题面、图片和公开样例，并重新绑定关卡工具。已归档、超过窗口或达到模型请求容量时创建新会话。模型实际读取的缓存由服务商决定。写入结果不明时，恢复操作会先核对平台状态。Web 面板提供脱敏日志和会话入口。

公网与专用部署中的所有作业会话均屏蔽 DSH Standard 原生工具，只向模型暴露当前关卡授权的专属工具（`educoder_*`）。代码、单选、多选、判断、填空及已配置执行器的 WebSSH 终端关卡可自动读写与提交评测；题干含图片时优先通过原生图片附件传递前 4 张可用图片。仅在暂不支持自动评测的题型或远端题图无法完整获取时，按配置提供无网络请求拦截的只读 `educoder_browser` 检查工具（不提供页面点击/控件操作工具）。每关可自动再试两次，短暂等待或平台结果不明确时优先读回核验。独立 VNC 图形实训仍需人工处理。

真实账号默认关闭。启用需要专用实例、通过检查的凭据隔离补丁、已授权的 EduCoder 签名配置，以及用户在受保护页面输入账号信息。真实作业执行另需显式启用并指定模型。DSH 以本地凭据服务保存会话，插件不保存原始密码。操作命令与回滚方式见 [开发实例部署](https://github.com/blueforst/dsh-toolkit-educoder/blob/main/deploy/educoder/README.md)。
